# P2P Chat
Чат без серверов: Windows / Android / Linux.

## Как получить сборки
1. Создайте репозиторий на GitHub, залейте туда содержимое этой папки (ветка main).
2. Вкладка Actions -> build -> когда закончится, внизу страницы Artifacts:
   p2pchat-windows (папка с .exe), p2pchat-android (.apk), p2pchat-linux (bundle).
   Можно запустить вручную: Run workflow.
3. Linux: для выбора файлов нужен zenity или kdialog, для эмодзи шрифт Noto Color Emoji.

## Как это работает
- Из ключа сессии (PBKDF2) выводятся: хэш комнаты и ключ AES-256-GCM. Сам ключ никуда не уходит.
- Участники находят друг друга через публичные WebTorrent-трекеры (видят только хэш и IP),
  дальше соединяются напрямую по WebRTC.
- При подключении участники сверяют id сообщений и досылают недостающие.
- Файлы адресуются по SHA-256 и проверяются после скачивания.
